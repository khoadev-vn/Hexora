# Hexora Landing Page 🚀

Next-Generation Cyberpunk / Minimalist Hero Landing Page for Hexora.

## ✨ Features
- **Cinematic Ambient Video Loop**: Smooth hardware-accelerated video background with subtle dark vignettes.
- **Brand Integration**: Official Hexora custom logo icon with fail-safe remote fallback.
- **GitHub Direct Routing**: All CTA buttons and navigation anchors link directly to [khoadev-vn/Hexora](https://github.com/khoadev-vn/Hexora).
- **Responsive Mobile Navigation**: Fluid 60fps hamburger menu crossfade with cubic-bezier animated backdrop and staggered links.
- **Interactive Quick-Scan Command**: One-click preview of `npx hexora .`.

## 🛠️ Quick Start

### 1. From root directory:
```bash
# Start development server (preview at http://localhost:3000)
npm run landing:dev

# Build production bundle
npm run landing:build
```

### 2. From landing directory:
```bash
cd landing
npm install
npm run dev
```

## 📦 Tech Stack
- **Framework**: React 18 + TypeScript + Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Video Source**: High-fidelity CloudFront MP4 stream
